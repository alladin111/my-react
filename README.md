📝 Todo List — React-приложение
Простое приложение для управления списком задач (Todo List), разработанное на React с использованием хуков и компонентного подхода.

🚀 Функциональность
➕ Добавление новых задач

📋 Просмотр списка всех задач

🗑️ Удаление задач по клику

✅ Валидация: нельзя добавить пустую задачу

📊 Отображение количества задач

🛠️ Технологии
React 18 (с хуками)

npm —  сборщик пакетов

CSS Modules / чистый CSS

Git для контроля версий

📦 Установка и запуск
1. Клонирование репозитория
bash
git clone https://github.com/alladin111/my-react.git
cd my-react
2. Установка зависимостей
bash
npm install
3. Запуск в режиме разработки
bash
npm run dev
или
npm start
После запуска откройте в браузере адрес, который появится в терминале (обычно http://localhost:5173).

🧩 Компоненты
Компонент	Описание
App	Управляет состоянием задач и полем ввода
TaskInput	Поле ввода и кнопка «Добавить»
TaskList	Отображает список задач
